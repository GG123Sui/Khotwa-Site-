# Khotwa | خطوة — TDC

مشروع واجهة ويب (HTML/CSS/JavaScript) قابل للنشر على GitHub Pages، ثم تغليفه كتطبيق Android عبر PWABuilder أو Capacitor.

## الملفات
- `index.html`: بنية الواجهة.
- `style.css`: التصميم المتجاوب.
- `app.js`: الأنشطة، العربية/الفرنسية، مشغل YouTube، المؤقت، وأرشيف الوسائط.
- `manifest.webmanifest`: إعدادات PWA.
- `sw.js`: دعم التخزين المؤقت للعمل الأساسي دون اتصال.

## قبل الاستخدام
1. افتح `app.js`.
2. ابحث عن `video: ""` داخل كل نشاط.
3. يمكن إدخال روابط YouTube من واجهة النشاط نفسها؛ الرابط يُحفظ على الجهاز.
4. المحتوى الحالي أمثلة عامة، ويجب أن يراجعه مختص TDC قبل النشر للعموم.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديداً وارفع جميع الملفات إلى الجذر.
2. من Settings > Pages اختر Deploy from a branch.
3. اختر `main` و`/(root)` ثم Save.
4. انتظر ظهور رابط الموقع. افتحه عبر HTTPS.

## تحويله إلى APK
GitHub Pages يستضيف الموقع ولا يحوّله وحده إلى APK.
أسهل مسار: افتح رابط GitHub Pages في PWABuilder، أكمل فحص PWA، ثم اختر Android package واتبع خطوات التوقيع والتنزيل.
إذا أردت بناء APK عبر Capacitor/Android Studio، يمكن إضافة Capacitor لاحقاً؛ هذا المشروع حالياً PWA ثابت ولا يحتوي إعدادات Gradle.

## ملاحظات الخصوصية والسلامة
- أرشيف الصور والفيديوهات يُخزّن محلياً في IndexedDB على الجهاز/المتصفح ولا يُرفع إلى خادم.
- لا توجد مزامنة أو نسخ احتياطي. حذف بيانات التطبيق أو المتصفح قد يحذف الأرشيف.
- لا تحفظ بيانات حساسة عن الطفل. احصل على موافقة ولي الأمر قبل التصوير، وأمّن الجهاز.
- يتطلب تشغيل YouTube اتصالاً بالإنترنت، وقد لا يعمل التضمين لبعض الفيديوهات بسبب إعدادات صاحب الفيديو.
- المؤقت والأرشيف وظائف مساعدة وليسا أدوات تقييم طبي.


## تحديث متطلبات PWABuilder
- تمت إضافة `icons/icon-192.png` و`icons/icon-512.png` وربطهما داخل manifest.
- تمت إضافة `id` و`categories` و`display_override` و`prefer_related_applications: false`.
- رسائل إضافة screenshots وIARC وrelated native app هي تحسينات/معلومات اختيارية غالباً، وليست كلها أخطاء تمنع إنشاء الحزمة. لا تضف `related_applications` إلا إذا كان لديك تطبيق Android منشور ومعروف بمعرّفه.
- بعد رفع الملفات المحدّثة إلى GitHub، افتح رابط الموقع ثم أعد فحصه في PWABuilder. تأكد أن روابط الأيقونات تفتح مباشرة.
